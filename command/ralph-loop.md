# Ralph Loop 启动命令

你正在启动 Ralph Loop —— 一种让 AI 持续迭代直到任务真正完成的机制。

## 使用方式

### 方式 1：完整规划流程（推荐）

直接调用 ralph-planner agent：

```
@ralph-planner
```

ralph-planner 会引导你完成：
1. 需求探索与澄清
2. 目标用例设计
3. 异常场景分析
4. 创建规划文件
5. 定义完成承诺
6. 确认后启动执行

### 方式 2：快速启动（已有规划）

如果 `.ralph/` 目录已存在且有完整的规划文件，直接调用：

```
@ralph-executor
```

### 方式 3：命令行参数

```
/ralph-loop [任务描述] [--quick]
```

参数说明：
- `[任务描述]`：可选，任务的简要描述
- `--quick`：可选，跳过详细规划，直接创建基本任务列表
