# Codex 专属规则

## 浏览器调用

### 本章作用

浏览器路径是验证环境的一部分。选择内置浏览器、系统浏览器、Playwright 或桌面浏览器会影响登录态、可见性、可控性和复现方式；先选对环境，再执行导航、点击、截图或调试。

### 选择规则

- 用户要求打开、导航、点击、检查、截图或调试本地 Web 页面时，优先使用 Codex 内置浏览器能力，尤其是 `localhost`、`127.0.0.1`、`::1` 和 `file://` 目标。
- 只有在用户明确要求系统默认浏览器、需要真实个人浏览器状态，或任务必须依赖外部浏览器登录态、扩展程序、证书、协议处理器时，才打开系统外部浏览器。
- 不要把 macOS `open`、系统默认浏览器、Playwright 启动的 Chromium/Chrome、Computer Use 控制的桌面浏览器混作同一种浏览器路径。
- 使用 Playwright 或项目测试命令启动浏览器时，应把它视为自动化验证环境，而不是默认外部浏览器；除非用户同意，不用它替代内置浏览器完成人工式页面检查。
- 当浏览器路径会影响结果，或需要偏离内置浏览器优先策略时，先简短说明将使用哪一种浏览器以及原因。
