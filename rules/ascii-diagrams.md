## Principle

ASCII 框图内的内容必须使用 **英文**，禁止使用中文。

## Reason

- GitHub 等宽字体渲染中文字符宽度不一致（视觉占 2 倍，实际按 1 字符计算）
- 中文导致框图边框对齐问题，不同平台/字体显示错位
- 英文字符宽度统一，框图对齐稳定可靠

## Examples

```
✓ Correct (English):
┌─────────────────────────────────────────────────────────────────────────────┐
│                           Architect                                         │
│  Responsibilities: Understand requirements, design solution, create plan    │
└─────────────────────────────────────────────────────────────────────────────┘

✗ Wrong (Chinese):
┌─────────────────────────────────────────────────────────────────────────────┐
│                           架构师                                            │
│  职责：理解需求、设计解决方案、创建可执行计划                               │
└─────────────────────────────────────────────────────────────────────────────┘
```

## Alternatives

- 框图外的说明文字可使用中文
- 表格、列表中的内容可使用中文
- 仅在 ASCII 框图内部强制使用英文
