# Web-Scraper 技能

研究外部资源、文档和最佳实践。

## 何时使用

- 需要比较库或框架
- 寻找最佳实践或模式
- 查找实现代码示例
- 验证技术可行性
- 查阅 API 或工具的文档

## 研究来源

### 优先级顺序

1. **官方文档** - 最权威
2. **GitHub 仓库** - 真实示例
3. **技术博客** - 深度解析
4. **Stack Overflow** - 具体问题解决方案
5. **社区论坛** - 讨论和观点

### 访问方法

| 来源 | 工具 |
|------|------|
| 库文档 | `context7` MCP 工具 |
| GitHub 代码 | `gh_grep` 或 GitHub 搜索 |
| 一般网页 | `websearch` 工具 |
| 特定 URL | `webfetch` 工具 |

## 工作流程

### 1. 明确研究目标

开始前需要明确：
- 需要回答什么具体问题？
- 什么决策依赖这项研究？
- 需要多深入的研究？

### 2. 搜索策略

```
研究查询制定：
- 从宽泛开始，逐步缩小范围
- 如相关，包含版本号
- 指定语言/框架上下文
```

### 3. 评估来源

**可信度指标：**
- 官方来源 > 社区来源
- 近期内容 > 过时内容
- 多来源一致 > 单一来源
- 可用示例 > 理论解释

### 4. 提取关键信息

对每个来源，记录：
- **主要洞见** - 核心要点
- **代码示例** - 可用的实现
- **注意事项** - 常见陷阱
- **依赖项** - 所需的包/配置

### 5. 综合发现

将信息整合为可操作的建议：
- 推荐什么方案？
- 为什么是最佳选择？
- 有哪些权衡？
- 存在哪些替代方案？

## 快速参考

### 库比较

```python
# 示例：比较 React 状态管理库

1. 搜索："zustand vs jotai vs recoil 2024"
2. 检查：各库的官方文档
3. 查找：GitHub stars、npm 下载量
4. 寻找：真实使用案例
5. 比较：包体积、API 简洁性、TypeScript 支持
```

### API 文档

```python
# 示例：查找 Stripe webhook 处理

1. 使用 context7：resolve-library-id "stripe"
2. 查询文档："webhook signature verification"
3. 提取：验证代码示例
4. 注意：所需环境变量
```

### 最佳实践

```python
# 示例：React 性能优化

1. 搜索："React performance best practices 2024"
2. 检查：React 官方文档优先
3. 寻找：useCallback、useMemo 指南
4. 查找：性能分析工具推荐
```

## 重要规则

- 始终引用来源 URL
- 优先使用官方文档而非博客文章
- 验证代码示例确实可用
- 记录所有引用的版本号
- 标记发现的任何冲突信息
- 永远不要编造或猜测信息
- 如无法找到信息，明确说明

## 常见模式

### 技术选型

1. 定义需求
2. 列出候选
3. 系统研究每个候选
4. 创建比较矩阵
5. 给出建议

### 实现指南

1. 查找官方文档
2. 提取设置步骤
3. 寻找可用示例
4. 识别常见陷阱
5. 汇编实现笔记

### 问题解决

1. 将问题重述为搜索查询
2. 查找 Stack Overflow 讨论
3. 检查官方 issue 追踪器
4. 查找相关文档
5. 综合解决方案
